# 코드·디렉토리 구조 검토

2026-09-08 로컬 검토 및 검증 결과입니다. 현재 기능을 유지하면서 이전 형식 지원과 실행 경로의 중복을 제거했습니다.

| 검토 영역 | 반영한 결정 |
|---|---|
| 앱 구성과 라우터 | Python 코드·템플릿·정적 파일을 `ranker/`로 모으고 `ranker.main:app`으로 실행합니다. 자원 경로는 패키지 위치에 고정했습니다. |
| 의존 관계 | 쿠키 정책을 `cookies.py`로 분리해 라우터의 앱 진입점 역참조를 제거했습니다. 서비스의 저장소 타입 참조는 실행 시 import하지 않습니다. |
| 평점·매칭 | 호환 어댑터를 제거하고 저장소·평점 엔진·매칭의 경계를 유지합니다. 후속 알고리즘 변경은 [gpl-map-v2 평가](algorithm_evaluation_v2.md)에 기록합니다. |
| 저장·백업 | JSON 세션 자동 이관, Elo 변환, 손상 필드 보정, 시작 시 `ALTER TABLE`을 제거했습니다. 현재 백업 형식 3의 필수 필드와 내용을 검증하며, 순위 응답별 횟수에서 모델을 재구축합니다. |
| 트랜잭션 | 저장 함수가 자신이 잠근 커넥션을 사용합니다. 세션 락, revision 검사, 취소 시 rollback, 차등 저장은 데이터 정합성을 위해 유지합니다. |
| 투표·이력 | 건너뛰기 입력은 문자열 `skip`으로 통일했습니다. 동률, 기록 보관, 취소와 재계산의 구분을 유지합니다. |
| 화면 | 기존 HTML·HTMX·공통 배틀 JavaScript 구성을 유지합니다. 구형 백업 변환 안내만 제거했습니다. |
| 빌드·배포 | Docker 파일은 `docker/`, Tailwind 원본은 `frontend/`, Playwright 설정과 서버는 `tests/browser/`에 둡니다. Compose·Fly·npm 실행 경로를 갱신했습니다. |
| 산출물 | pytest·Ruff·Playwright 산출물은 `.cache/`에 모읍니다. Docker 빌드 컨텍스트에는 필요한 소스·명세·라이선스만 포함합니다. |
| 의존성·문서 | 새 패키지를 추가하지 않았습니다. 기존 잠금 파일을 사용하고 README의 구조·실행 명령·저장 계약을 갱신했습니다. |

루트의 의존성 명세·잠금 파일, Compose·Fly 설정은 기본 도구 명령이 찾는 위치에 유지합니다. 별도 설정 계층이나 경로 호환용 파일은 추가하지 않습니다.

입력 검증, 외부 리다이렉트 차단, 최근 후보가 소진됐을 때 반복 대결 허용, 다음 카드 렌더 실패 시 페이지 이동은 현재 기능의 오류 처리입니다. 이러한 동작은 이전 버전 지원과 구분해 유지합니다.

## 검증

- Python: `uv run pytest -q` — 167개 통과. 제거된 변환·이관 테스트 5개 대신 구형 백업 거절, 손상 백업의 저장 데이터 보존, 다른 작업 디렉토리에서의 자원 로딩·앱 수명주기 테스트 10개를 추가했습니다.
- JavaScript: `npm run test:js` — 10개 통과.
- 브라우저: `RANKER_CHROME_PATH=/usr/bin/google-chrome npm run test:browser` — 데스크톱·모바일 다크모드 12개 통과. 임시 DB에서 투표, partial 교체, 건너뛰기, 취소, 항목·기준 편집, 목록 복구와 백업 교체를 검증했습니다.
- `npm ci`, CSS 빌드, Ruff 검사·포맷 검사, `docker compose config --quiet`, `git diff --check` 통과.
- 개발·배포 Docker 이미지 빌드 및 임시 데이터 영역에서 HTTP 기동 검증 통과: health, 랭킹 생성·항목 저장·내보내기, 랭킹 페이지, JS/CSS 제공. 배포 프로세스 UID 1000, 라이선스 포함, 테스트 소스 제외도 확인했습니다.
- 평가 도구: `uv run python -m scripts.evaluate_algorithm --seeds 1 --output .cache/algorithm-smoke.json` 실행 성공. 명령·import 경로 확인이며 기존 알고리즘 평가 보고서를 갱신하는 실험은 아닙니다.

## 운영 조건과 미검증 사항

기존 DB를 사용하려면 현재 스키마(`sessions.revision` 포함)가 필요합니다. 이전 백업 형식과 자동 DB 마이그레이션은 지원하지 않습니다. 로컬 데이터 파일은 수정하지 않았고 기존 루트 캐시·테스트 결과·Node 의존성 디렉토리는 `.cache/previous-root/`에 보존했습니다.

실제 Fly 배포, 운영 볼륨의 스키마·데이터 검증, 다중 워커 운영은 수행하지 않았습니다. 앱은 계속 단일 워커를 전제로 합니다.
